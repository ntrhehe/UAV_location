

\## 项目背景与技术路线



\### 项目目标



利用大疆M4E无人机航拍照片（倾斜视角JPG），进行\*\*电杆（utility pole）的地理定位\*\*——即检测出每根电杆的精确经纬度坐标。



\### 核心挑战



1\. \*\*单张照片像素→地理坐标精度不足\*\*：已验证`pixel\_to\_geo\_dem.py`（光束法+DSM射线求交）单张精度约3m偏差，不满足要求。根本原因是云台角度误差（1°≈178m高度→3.1m地面偏移），且DJI Terra的平差优化会降低单张绝对精度（优化目标是多张一致性，非单张绝对精度）。



2\. \*\*DOM正射影像看不到电杆\*\*：DOM是从正上方垂直投影生成的，电杆在DOM中会坍缩成一个小点。而原始倾斜JPG中电杆清晰可见——因为中心投影+高度差，pitch=-90°时电杆仍以放射状"躺倒"在画面中。



3\. \*\*大量重叠照片\*\*：一个航拍文件夹有1000张照片，大量重叠，不能全用。



\### 拟确定的技术路线



```

输入：N张倾斜JPG + pos优化.csv(优化后位姿) + cam.txt(相机标定) + DSM.tif + DOM



阶段1：智能照片筛选

├─ 从pos优化.csv解析每张照片的(lat, lon, alt, yaw, pitch, roll)

├─ 简化估算每张照片的地面footprint（假设平坦地面，飞行高度178m，传感器参数M4E）

├─ 30m×30m网格划分测区

├─ 计算每张照片覆盖的网格 → 建立倒排索引

├─ 建立重叠图（两张照片共享≥15%网格 → 视为相邻）

├─ 贪心+连通性约束筛选：

│   · 目标：覆盖最多未覆盖网格

│   · 约束：选中照片必须与已选子集连通（有重叠边）

│   · 惩罚：冗余覆盖扣分

└─ 输出：40-60张最优照片子集 + GeoJSON可视化



阶段2：图像拼接（待实现）

├─ 选出的照片做SIFT/SuperPoint特征匹配

├─ 粗对齐（利用地理位置） + 精对齐（局部单应性）

├─ 拼接成一张无地理参考的大图



阶段3：DOM配准（待实现）

├─ 在拼接大图和DOM上选控制点（地面特征：路口、标线、建筑角）

├─ 计算仿射/薄板样条变换

└─ 赋予拼接大图精确地理坐标



阶段4：检测+定位（待实现）

├─ YOLO在拼接大图上检测电杆

├─ 取框底部中心（电杆接地点）

├─ 通过配准变换 → 精确lon/lat

└─ 轻量去重（邻接重叠区可能少量重复）

```



\### 设计考量



\- \*\*重叠保留\*\*：不能完全消除重叠，因为需要重叠区域做SIFT匹配来实现图像空间对齐

\- \*\*冗余控制\*\*：每格不超过2-3张照片覆盖，减少电杆重影

\- \*\*电杆定位用底部中心\*\*：接地点在DSM射线上是准确的，顶部像素会有投影偏移

\- \*\*pitch=-90°也能用\*\*：中心投影下电杆不消失，以放射状躺倒呈现

\## 需求



请基于上述背景和技术路线，实现 `photo\_selector.py` 的阶段1筛选功能，具体要求：



1\. \*\*读取数据\*\*：从`test/pos优化.csv`解析所有照片的位姿，匹配`test/img/`目录下实际存在的JPG文件

2\. \*\*估算footprint\*\*：用简化几何模型（高度+传感器参数+正射假设+20%margin）估算每张照片的地面覆盖范围

3\. \*\*网格覆盖\*\*：30m×30m网格划分测区，计算每张照片覆盖的网格

4\. \*\*重叠图\*\*：两张照片共享≥15%网格时建立邻接边

5\. \*\*贪心筛选\*\*：带连通性约束——第一张选覆盖最多的，后续每张在连通到已选子集的前提下选净贡献最大的

6\. \*\*输出\*\*：

&#x20;  - 控制台打印筛选结果统计

&#x20;  - `test/selected\_photos.txt`：选中的照片文件名列表

&#x20;  - `test/selection\_viz.geojson`：覆盖可视化（QGIS可打开查看）



全部使用纯Python标准库实现（csv、math、json、os、pathlib），不依赖numpy/PIL/rasterio等。
